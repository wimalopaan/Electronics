Jeder Projektabschnitt verwendet dieselbe Struktur, damit die Leser dieselben Informationen immer an derselben Stelle finden.
Kopiere das folgende Grundgerüst in das entsprechende Dokument unter `docs/` und füge der Tabelle zum
<<../README.de.adoc#project-status,Projektstatus>> in der README eine Zeile hinzu.

[NOTE]
--
Es werden nur die Zeilen benötigt, die auf das Projekt zutreffen. Statuswerte: `🟢 aktiv`, `🔵 stabil`, `🟡 experimentell`, `📝 geplant`, `⚪ abgelöst`.
--

....
