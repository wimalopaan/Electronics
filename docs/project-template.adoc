Every project section uses the same structure, so readers find the same information in the same place.
Copy the following skeleton into the corresponding document in `docs/` and add a row to the
<<../README.adoc#project-status,project status>> table in the README.

[NOTE]
--
Only rows that apply to the project are needed. Status values: `🟢 active`, `🔵 stable`, `🟡 experimental`, `📝 planned`, `⚪ superseded`.
--

Schematic, PCB, images, production data.

=== Firmware

=== Configuration and usage
