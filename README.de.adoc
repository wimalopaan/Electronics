[[ieee]]
== IEEE: der RC-Software-Verbund (Stack)

`EdgeTx`, `ExpressLRS` und `ESCape32` sind _die_ Kombination von RC-bezogenen Open-Source-Softwareprojekten, die ich
inzwischen in allen meinen Modellen verwende.

[NOTE]
--
Die drei großen `E`s: `EdgeTx`, `ExpressLRS` und `ESCape32`
--

Wenn ich eine Funktion wie _Return-to-Home_ (automatische Rückkehr zum Startpunkt) benötige, würde ich eindeutig `INAV` wählen.
Zusammen ergibt das also `EEEI`.

[IMPORTANT]
--
Wenn man `EdgeTx`, `ExpressLRS`, `ESCape32` und `INAV` auf einen Stapel legt, sie wieder herunternimmt und jeweils den ersten Buchstaben verwendet,
ergibt das `IEEE`, den *RC-Software-Stack* (bitte nicht mit https://www.ieee.org[] verwechseln, das ist eine andere wichtige Sache ;-) ).
--

[[_projects]]
== Projekte

Die unter <<documents>> aufgeführten Dokumente beschreiben einige meiner aktiven Projekte. Die meisten meiner früheren Projekte (siehe <<Old.adoc#,alte Seite>> auf Deutsch)
werden inzwischen nicht mehr weiterentwickelt. Der Grund dafür ist, dass ich bei den µCs vollständig von der AVR-Familie (DA, DB, tiny1/2) auf die leistungsfähigere
STM32-Familie umgestiegen bin, hauptsächlich auf STM32G4xx und STM32G0xx. Diese bieten genügend Rechenleistung für das Projekt <<docs/vhf-receivers.de.adoc#sdr,SDR-RC-Empfänger für 27/35/40MHz>>, das mit
AVRs nicht möglich gewesen wäre. Auch die G0xx verfügen über genügend interne Peripherie, um all diese verrückten RC-Ideen bequem umzusetzen.

Eine Ausnahme gibt es allerdings: die <<docs/vhf-receivers.de.adoc#corona,Ersatzfirmware für den Corona RP8D1>>.
